# Incursion Red River Item List

A community item finder for Incursion Red River. Look up weapons, attachments, ammo, keys and more, then copy the command you need.

**[Open the interactive item list](https://felix2331fai.github.io/Incursion-Red-River-Item-List/)**

## Find an item in three steps

1. Search for an item or open a category to browse.
2. Click the item name to copy a command for one or click a quantity button.
3. Paste the command into the in-game console and press Enter.

Looking for loadout ideas? [Browse Firestar’s weapon builds](Weapon%20builds%20by%20Firestar.htm).

## Help keep the list useful

Found a missing item, a command that failed or a build worth sharing? A quick note is enough. If you're reporting a command, please include what you pasted and your game version (if you know it).
